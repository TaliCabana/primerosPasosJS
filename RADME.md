# 📘 Trabajo Práctico N.º 1 – Introducción a JavaScript

Este repositorio contiene el primer trabajo práctico del curso de JavaScript de RollingCode School – Comisión CWeb13.  
Se trabajaron los conceptos fundamentales del lenguaje y la lógica de programación a través de ejercicios prácticos.

## 🧠 Contenidos aprendidos

Durante este TP se aplicaron los siguientes conceptos:

### 🧩 Estructuras de control
- `if`, `else`, `else if` ➡️ Para evaluar condiciones y tomar decisiones.

### ✂️ Manejo de cadenas de texto
- `charAt()` ➡️ Para acceder a un carácter específico dentro de una cadena.
- `length` ➡️ Para conocer la cantidad de caracteres en una cadena.
- `toUpperCase()` y `toLowerCase()` ➡️ Para convertir texto a mayúsculas o minúsculas.

### 📦 Declaración de variables
- `let` y `const` ➡️ Para declarar variables que pueden (o no) modificarse.

### 🖨️ Entrada y salida de información
- `console.log()` ➡️ Para imprimir mensajes en la consola.
- `prompt()` ➡️ Para solicitar datos al usuario.
- `alert()` ➡️ Para mostrar mensajes emergentes.


## 🚀 Cómo ejecutar
Clonar el repositorio escribiendo en una terminal el siguiente comando: `git clone https://github.com/TaliCabana/TP1JS.git`

1. Abrí el archivo index.html en un navegador.

1. Interactuá con los ejercicios desde el navegador.

1. Revisá la consola del navegador (F12 o clic derecho → "Inspeccionar") para ver los console.log() si aplica.
